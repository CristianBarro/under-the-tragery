# Under the Tragery — O Mar Ainda Lembra

![Under the Tragery](docs/capa.jpg)

RPG 2D de exploração submarina, sobrevivência e terror psicológico. Prólogo, três atos, três finais e a expansão de expedições. Inclui o modo **Vida em Atlântida**: dez áreas, produção, moradia, calendário, relações entre personagens, romance e família.

## ⬇️ Download

Baixe a versão mais recente em **[Releases](../../releases/latest)**:

| Plataforma | Arquivo | Requisitos |
| --- | --- | --- |
| Windows | `Under-the-Tragery-Windows-1.5.0.exe` | Windows 10/11 64 bits. Portátil: abra e jogue, sem instalador. |
| Android | `Under-the-Tragery-Android-1.5.0.apk` | Android 8.0+ com Android System WebView atualizado. Jogue na horizontal. |

Funciona offline. O progresso fica salvo no aparelho.

## Controles (Windows)

| Ação | Tecla |
| --- | --- |
| Mover | WASD / setas |
| Agir | E |
| Lanterna / Sonar / Foto | F / Q / C |
| Inventário / Mapa | I / J |
| Trocar / usar suprimento | Z / X |
| Ajuda | H ou F1 |
| Tela cheia | F11 ou Alt+Enter |
